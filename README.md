# Dry Horns Studio landing page

Static site for GitHub Pages. Upload `index.html`, `styles.css` and the `assets/` folder to the root of the `dryhornsstudio.github.io` repository.

- Contact: dryhornsstudio@gmail.com
- Instagram: https://www.instagram.com/dryhornsstudio/
- Game: https://atlasarg.itch.io/balanced-dungeons

To add a game later, duplicate the `game-card` block in `index.html` and edit its title, description and link.

The site uses Google Fonts when available and falls back to local serif/sans-serif fonts.
